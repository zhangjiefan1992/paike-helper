## Why

教练们目前使用手机备忘录以纯文本方式记录排课信息，无法一眼看出一周空档、难以跟踪课程状态和会员上课历史。需要一款轻量级微信小程序，让教练以结构化方式管理课程排期和会员信息，数据完全本地存储、无需后端。

## What Changes

- 将当前微信小程序默认模板重构为完整的排课管理应用
- 新增周视图首页，7 列布局展示一周排课概览，支持左右滑动切换周
- 新增日视图，时间轴形式展示单天课程详情，支持左滑快捷操作
- 新增课程录入/编辑表单，支持私教和团课两种模式
- 新增会员管理模块（列表、详情时间轴、新增/编辑）
- 新增设置页，包含预设配置管理和数据导入导出
- 建立本地数据层（storage.js），封装会员/课程/配置的 CRUD 操作
- 建立主题系统，通过 CSS 变量控制全局视觉，内置"动漫暖系"默认主题
- 新增可复用组件：课程卡片、空状态、标签、会员头像

## Capabilities

### New Capabilities
- `data-layer`: 本地数据存储层，包含会员/课程/配置的 CRUD、日期工具、ID 生成、数据导入导出
- `week-view`: 周视图首页，7 列排课概览、周切换、统计摘要、空状态
- `day-view`: 日视图，时间轴布局、课程卡片左滑操作、空白时段快速排课
- `session-management`: 课程录入/编辑/删除，私教与团课模式、表单校验、冲突检测
- `member-management`: 会员增删改查、列表搜索排序、详情页统计卡片与上课时间轴
- `settings-and-backup`: 设置页，预设配置管理、数据 JSON 导出/导入、主题入口预留
- `theme-system`: CSS 变量主题系统，动漫暖系默认主题，预留多主题切换架构
- `shared-components`: 可复用组件（session-card、empty-state、tag、member-avatar）

### Modified Capabilities

（无已有 capabilities）

## Impact

- **页面路由**：`app.json` 从 2 个模板页面重构为 7 个业务页面 + 3 Tab 导航栏
- **全局样式**：`app.wxss` 重写为主题变量系统
- **应用入口**：`app.js` 重写为数据层初始化逻辑
- **新增目录**：`utils/`（4 个工具模块）、`data/`（默认配置）、`components/`（4 个组件）、`assets/images/`（图标和插画）
- **删除内容**：移除默认模板的 `pages/index/` 和 `pages/logs/` 页面
- **依赖**：无外部依赖，仅使用微信小程序原生 API
