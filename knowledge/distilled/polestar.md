## 核心理念

- 循证实践（Evidence-Based Practice）
- 临床推理驱动训练设计
- 普拉提作为康复工具，不仅是健身方法
- 六大原则：呼吸、轴向延伸、脊柱关节运动、核心控制、动作效率、体重承载
- 注重评估 → 训练 → 再评估的循环

## 训练原则

- 以评估为起点（posture assessment / movement screening）
- 训练目标 = 纠正功能障碍，不是做完动作
- 渐进康复：疼痛管理 → 活动度恢复 → 稳定性 → 功能性
- 注重本体感觉和神经肌肉控制
- 呼吸整合：呼吸模式异常是首要纠正目标

## 常见动作家族

### 评估工具
- Standing Posture Assessment
- Roll Down Assessment（观察脊柱节段活动）
- Single Leg Stance（平衡 + 骨盆稳定评估）
- Breathing Pattern Assessment

### 康复基础
- Diaphragmatic Breathing（膈肌呼吸训练）
- Pelvic Floor Activation
- Deep Cervical Flexor Activation（深层颈屈肌）
- Scapular Setting（肩胛骨归位）
- Transversus Abdominis Isolation

### 脊柱康复
- Cat-Cow（节段控制版）
- Book Openings（胸椎旋转）
- Thread the Needle
- Prone Extension（腰椎 neutral 下的伸展）
- Side-Lying Thoracic Rotation

### 下肢 / 髋部康复
- Clam（经典髋外旋激活）
- Bridge with Pelvic Control
- Hip Hinge Training
- Single Leg Balance Progressions
- Knee Alignment Work

### 器械应用（康复导向）
- Reformer: Footwork（矫正足踝对线）
- Reformer: Knee Stretch（膝关节控制）
- Cadillac: Roll Down Bar（脊柱逐节控制）
- Chair: Seated Pumping（术后早期负重）

## 特殊人群注意事项

- **术后康复**：北极星的核心强项。按术后阶段（急性→亚急性→功能恢复→回归运动）设计
- **慢性疼痛**：避免疼痛加重的动作，以无痛范围渐进
- **神经系统问题**：帕金森/中风后——节奏训练、平衡挑战、大幅度运动
- **骨质疏松**：避免脊柱屈曲加压、避免跌倒风险动作
- **孕期/产后**：从骨盆底评估开始，分阶段恢复核心功能

## 与其他流派的差异

| 对比维度 | 北极星 | 其他 |
|---------|--------|------|
| 核心定位 | 康复/临床 | 罗马纳/BASI 偏健身 |
| 起点 | 评估 + 临床推理 | 罗马纳从固定序列开始 |
| 动作目的 | 纠正功能障碍 | BASI 追求体能表现 |
| 客户类型 | 损伤/术后/特殊人群 | 斯多特更通用人群 |
| 教练背景 | 多为物理治疗师转型 | 其他多为运动/舞蹈背景 |

## AI Agent 使用指引

当以北极星视角分析时：
1. 首先关注安全和禁忌（伤病史 / 手术史 / 疼痛位置）
2. 提出评估建议（"建议先评估 XX"）
3. 以康复分阶思路设计：当前阶段 → 目标 → 渐进路径
4. 对高风险动作明确标注警告（⚠）
5. 如果会员无损伤史，说明"从北极星视角无特别禁忌，建议参考其他流派的训练强度建议"
