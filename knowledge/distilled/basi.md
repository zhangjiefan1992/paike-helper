## 核心理念

- Block System（模块化训练系统）
- 强调身体艺术与科学的结合
- 注重功能性体能和运动表现
- BASI Pilates Flow：动作之间无停顿，保持动态流畅
- 力量 + 柔韧 + 控制三者平衡

## 训练原则

- Block System 编排法：将训练分为功能性模块（Warm-up / Footwork / Hip Work / Spine / Lateral / Full Body / Stretch）
- 强度渐进：同一动作通过杠杆、弹簧、速度调整难度
- 流畅过渡（Flow）：模块之间无停顿
- 双向训练：向心 + 离心同等重视
- 呼吸 = 动力源（用呼吸产生力量，非仅放松）

## 常见动作家族

### Block 1: 热身 / 核心激活
- Pelvic Curl（骨盆卷动）
- Chest Lift（胸椎离地）
- Hundred（BASI 版本：强调力量输出）
- Spine Twist Supine

### Block 2: 下肢 / 髋部
- Leg Circle（大幅度版）
- Single Leg Kick
- Double Leg Kick
- Side Kick Series（Front/Back, Up/Down, Circle）
- Inner Thigh Lift

### Block 3: 脊柱
- Roll Up（力量版，不靠惯性）
- Swan Dive（全幅度）
- Swimming（高强度持续版）
- Jackknife

### Block 4: 全身整合
- Teaser（全系列 I/II/III）
- Control Balance
- Push-Up Series
- Star / Twist

### 器械（强度导向）
- Reformer: Long Stretch → Down Stretch → Up Stretch（连续流）
- Reformer: Jumping Board（爆发力训练）
- Chair: Pike / Tendon Stretch（高难度）
- Cadillac: Hanging Pull-Up / Push-Up

## 特殊人群注意事项

- **运动员**：BASI 的强项——用 Block System 设计运动专项训练
- **体能目标**：可加入 Jumping Board、高弹簧阻力、动态变速
- **减脂塑形**：高强度流畅编排（HIIT-Pilates 风格）
- **初学者**：降低杠杆、减少弹簧、放慢节奏——但保持 Flow 不断
- **损伤人群**：非 BASI 主要定位，建议优先参考北极星方案后，再用 BASI 渐进提强

## 与其他流派的差异

| 对比维度 | BASI | 其他 |
|---------|------|------|
| 训练强度 | 最高（体能导向） | 罗马纳/斯多特中等 |
| 编排逻辑 | Block System 模块化 | 罗马纳固定序列，斯多特自由 |
| Flow 要求 | 极强（无停顿） | 北极星允许评估停顿 |
| 目标人群 | 运动员/体能追求者 | 北极星偏康复 |
| 动作幅度 | 大幅度 / 全 ROM | 北极星偏保守控制 |
| 呼吸角色 | 产生力量 | 其他偏放松/稳定 |

## AI Agent 使用指引

当以 BASI 视角分析时：
1. 评估当前体能水平和训练目标
2. 用 Block System 思路编排（模块化 + Flow 连接）
3. 强调强度渐进方案（杠杆/弹簧/速度三维度）
4. 适合"想要挑战"的会员——如果目标是康复保守，明确说明
5. 对于有伤病限制的会员，优先标注"建议先参考北极星方案确认安全范围，再回到 BASI 强度渐进"
