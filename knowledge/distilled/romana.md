## 核心理念

- 忠于 Joseph Pilates 原始教学体系
- 强调控制（Contrology）、呼吸、中心、精准、流畅、专注六大原则
- 固定动作序列（mat work + apparatus），不随意修改顺序
- "先学基础，再进阶"——严格分级体系

## 训练原则

- 全身整合而非局部训练
- 呼吸引领动作节奏
- 动作间保持流畅过渡（flow）
- 对称性：左右交替平衡
- 反复练习直到动作内化

## 常见动作家族

### 垫上（Mat）
- The Hundred
- Roll Up / Roll Over
- Single Leg Circle
- Rolling Like a Ball
- Series of Five（Single Leg Stretch / Double Leg Stretch / Single Straight Leg / Double Straight Leg / Criss-Cross）
- Spine Stretch Forward
- Open Leg Rocker
- Teaser 系列
- Swimming
- Seal

### 器械（Apparatus）
- Reformer: Footwork → Hundred → Short Box → Long Stretch 系列
- Cadillac: Roll Down Bar / Leg Springs / Push Through
- Wunda Chair: Pumping / Going Up Front / Tendon Stretch
- Barrel: Short Box / Swan

## 特殊人群注意事项

- **孕期**：避免仰卧位（16 周后）、深度扭转、高强度腹部加压
- **腰椎问题**：避免过度屈曲（Roll Up 可用 Roll Down 替代）、控制骨盆中立
- **老年**：降低节奏、增加稳定支撑、减少地面转移
- **术后康复**：非罗马纳主要领域，建议转介北极星/康复方向

## 与其他流派的差异

| 对比维度 | 罗马纳 | 其他 |
|---------|--------|------|
| 动作序列 | 固定顺序 | 斯多特/北极星可自由编排 |
| 脊柱位置 | 偏重 imprint | 斯多特强调 neutral spine |
| 器械使用 | 原始 Gratz 器械 | BASI/斯多特有现代改良版 |
| 教学风格 | 严格师徒制 | 其他更灵活 |
| 适用人群 | 健康成人为主 | 北极星偏康复特殊人群 |

## AI Agent 使用指引

当以罗马纳视角分析时：
1. 优先考虑经典动作序列中与目标区域相关的段落
2. 强调呼吸与控制的结合
3. 建议按照分级体系推进（基础→中级→高级）
4. 如遇特殊人群（损伤/孕期），明确标注"超出本流派主要范围，建议参考北极星视角"
