# 排课助手 MVP 商业决策记录

> 本文档记录排课助手从零到 MVP 的所有战略决策、市场调研结论、定价方案，供后续开发参考。
> 更新于 2026-05-14

---

## 一、产品定位

**一句话：** 帮自由教练在每节课后，用 3 秒发出一条 AI 自动生成的专业课程总结给学员。

**目标用户：** 自由私教（瑜伽/普拉提/健身），不依附场馆，自己接学员，1-5 人工作室。

**核心差异：** 不是 SaaS 管理工具（不做财务/营销/多门店），是**教学辅助工具**。
- 竞品（青橙、松果、菲特云）面向场馆老板，需要营业执照，功能大而全
- 排课助手面向自由教练本人，不需要营业执照，极简

## 二、市场调研关键结论

### 竞争格局（2026.05）

| 竞品 | 价格 | 规模 | 关键信息 |
|---|---|---|---|
| 青橙科技 | 免费基础版 / Pro ¥19.9/人/月 | 30,000+ 场馆 | 2014 年起家，从教练端免费工具切入 → 病毒传播 → 向上卖工作室 |
| 松果约课 | ¥365/年 | 瑜伽/普拉提馆 | 拟真卡设计、微信卡包集成 |

| 菲特云 | 免费小程序 | 健身工作室 | SaaS 综合平台 |

### 价格锚点
- 市场年费区间：¥300-3,000/年
- 青橙最大的动作：2019 年将小程序**永久免费**，靠后端 SaaS 收费
- 青橙新玩法：14 人以下工作室按账号数量付费，¥19.9/人/月

### 关键发现：面向教练的"课后总结"市场空白
- 调研了 20+ AI 健身产品（Flexion、FitBot、SensAI、PRPath 等），**100% 面向消费者**（帮用户练），不是面向教练（帮教练教）
- 没有产品帮教练管理课程照片/视频、自动生成课后总结
- 这是蓝海

### 微信生态发现
- **AI 运动识别小程序插件**（wx6130e578c4a26a1a）：离线本地 AI 动作识别，支持深蹲/俯卧撑/卷腹/平板支撑等。可用于未来体态评估功能。
- **微信同声传译插件**（wx069ba97219f66d99）：内置语音识别。需企业认证。

## 三、产品功能架构

### MVP 核心闭环

```
上课前：排课助手排好课（周视图）
上课中：教练可选的录音（点一下🎤开始）
下课后：打开小程序 → 课程卡片红点 🔴 → 点"发送总结"
       → AI 已自动生成专业课程总结（含语音转写内容）
       → 同时 AI 在后台更新学员成长档案（LLM Wiki 模式）
       → 教练看一眼，点发送
       → 学员微信收到专业复盘
```

### 核心功能模块

| 功能 | 说明 |
|---|---|
| 排课 | 周视图拖拽排课，绑定学员 + 课程类型 + 时长 |
| AI 课后总结 | AI 基于课程信息 + 历史数据 + 录音文字自动生成 |
| 语音转写 | FunASR（阿里云百炼）将课程录音转文字，充当总结信息源 |
| 学员档案 | LLM Wiki 模式，每次课后 AI 自动更新学员完整画像 |
| 云同步 | 微信云开发 CloudBase，数据云端备份 |
| 课程默认训练重点 | 设置一次，每节同类型课自动勾好训练重点 |

### AI 总结质量保证机制

- **第 1 次课**：课程名称 + 时长 + 选中的训练重点 + 通用专业建议
- **3-5 次课后**：开始出现纵向对比
- **10 次课后**：个性化深度，接近教练语言风格
- **教练编辑反馈闭环**：教练修改的内容被系统学习，未来总结更接近教练本人风格

### 课后总结信息源（AI 自动获取，无需教练输入）

1. 学员姓名 ← 排课时绑定
2. 课程类型 ← 排课时选择
3. 课程时长 ← 排课时设置
4. 训练重点 ← 课程类型默认预设（设置一次，永久自动勾好）
5. 该学员历史档案 ← AI 持续维护
6. 录音文字（可选）← FunASR 转写

### 不做的功能（MVP 阶段）

- 功能分级限会员数
- 订阅制自动续费
- 多设备实时同步
- 会员端小程序（学员端）
- 主题商店/模板市场
- 教练社区/UGC
- 团购/电商

## 四、定价方案

### 三档容量制（功能全给，不阉割）

| | 免费版 | 标准版 | 专业版 |
|---|---|---|---|
| 价格 | ¥0 | **¥9.9** | **¥29.9** |
| 功能 | 全量 | 全量 | 全量 |
| AI 课后总结 | 15 次/月 | 100 次/月 | 无限 |
| 语音转写 | 60 分钟/月 | 300 分钟/月 | 1200 分钟/月 |
| 学员上限 | 15 人 | 50 人 | 无限 |
| 云同步 | ❌（唯一功能缺失）| ✅ | ✅ |
| 学员档案 PDF | ❌ | ❌ | ✅ |
| 广告 | 可选激励视频（换额外次数）| 无 | 无 |

### 定价逻辑

- **¥9.9**：教练一节私教课 ¥400-600，¥9.9 = 一节课收入的 2.5%。不存在"贵"这个概念。
- **¥29.9**：多 ¥20 = 多个不用付月薪的"AI 助教"。
- 买断制 → 无续费焦虑，冲动消费门槛低。
- 后续可升级为年付订阅，但 MVP 先跑通支付链路。

### 广告策略

- 只在免费版中出现，作为升级推手（非收入主力）
- 激励视频：用完 AI 总结次数后，可看 15 秒视频换 1 次额外次数
- 设置页底部小 banner（不打扰工作流）
- **绝不在周视图、课程总结页、学员页放广告**

## 八、技术架构关键点

### 微信云开发（CloudBase）
- 环境创建 → 获取 envId
- 数据库集合：pk_users（用户/付费状态）、pk_sync_members、pk_sync_sessions、pk_sync_config
- 成本：¥19.9/月基础套餐

### 语音转写架构
```
小程序端：wx.getRecorderManager() 录音 → wav 文件
云函数：接收音频 → OSS → FunASR API → 返回文本 → LLM 总结
```
- FunASR 模型：fun-asr-realtime，16kHz，支持普通话 + 方言
- 无需实时流式，课后异步处理即可

### LLM Wiki 学员档案
- 每次课后：读取当前档案 + 新课信息 → LLM 重写完整档案
- 不是"新增记录"，是"理解 → 更新 → 重写"
- 和课后总结同一次 API 调用，零额外成本

### 微信支付
- 接口：`wx.requestPayment`（单次支付）
- 云函数：createOrder / verifyPayment
- 商户号申请：5-15 工作日

3. "¥9.9 永久使用，你会付吗？"
4. "你现在用什么排课？最大的烦恼是什么？"


## 十、产品哲学

- **零输入原则**：能自动生成的绝不让人输入
- **3 秒完成原则**：核心操作不超过 3 次点击
- **下课才用原则**：不在课中打扰教练
- **学员能感知原则**：产品好不好，学员收到什么比教练操作什么更重要
- **利他原则**：不是卖东西给教练，是帮他做更对的选择
- **信任升级原则**：免费体验完整功能 → 用量不够了自然付费 → 数据越多越离不开
