# MVP 定义 & 实现路径

> 版本：v2.0
> 最后更新：2026-05-21
> **北极星指标：录入速度。"快" 是这个产品的唯一核心竞争力。**

---

## 一、产品定位（一句话）

**让教练用说话的速度，完成排课、记录、查询。**

竞品的本质都是 Excel + Form 的封装；我们的本质是 ASR + LLM Agent + 数据结构化的极简前端。**录入耗时是其他工具的 1/6**——这就是杀手锏。

---

## 二、MVP 验证标准

MVP 上线后，**全部满足才算过线**：

| # | 检验项 | 标准 |
|---|--------|------|
| 1 | 录入速度 | 单条课程录入 ≤ 10 秒（含 AI 解析）|
| 2 | 用户切换 | 老婆 / 内测教练连续用 1 周不回退到备忘录 |
| 3 | 主动分享 | 用户主动截图周视图发会员 |
| 4 | 客档查询 | 用户觉得"翻 AI 档案" 比"翻聊天记录" 顺 |
| 5 | 留存 | 每周至少 3 次主动打开 |

## 四、Phase 3：AI Agent 模式（MVP 上线后启动）

> 这是产品**第二曲线**，不是 MVP 必需。但要在架构上为它留好接口。

### 4.1 定位

不是新产品，是当前产品的**激进模式入口**。主页加一个超大录音按钮：

```
┌──────────────────────────────────────────┐
│   🎙  一句话搞定                          │
│       排课 · 改课 · 记录 · 查询           │
│                                          │
│   本周 12 节 · 今天 3 节                  │
└──────────────────────────────────────────┘
[+ 新建课程]  [📅 周视图]  [👥 会员]  ← 传统入口保留
```

按下后用户口喷 → Agent 解析多意图 → 列出"AI 计划做这些事" → 用户确认。

### 4.2 Agent 架构（你的经验在此发挥）

参考 agentscope-java 模型，定义：

**工具集（Tools）**
- `create_session(date, time, member, courseType, ...)`
- `update_session(sessionId, fields)`
- `cancel_session(sessionId)`
- `query_sessions(member|date|range)`
- `create_member(name, ...)`
- `update_member_profile(memberId, notes)`
- `add_post_class_note(sessionId, text)`
- `generate_suggestion(memberId, topic)`

**System Prompt 行为骨架**
- 角色：教练个人助理
- 输入：教练的口述（可能含多意图）
- 输出策略：
  - 步骤 1：识别所有意图（可能多个）
  - 步骤 2：消歧（"她" → 上下文最近的会员）
  - 步骤 3：列出执行计划
  - 步骤 4：等待用户确认（**不直接落库**）
- 不确定时主动 ask clarification

**Skill 划分（建议）**
- `Scheduler`：管排课增删改查
- `MemberProfile`：管会员档案 / 标签 / 备注
- `Coach`：生成课后建议、训练计划、关注提醒

### 4.3 技术形态

- **传输**：SSE 流式输出 agent 思考链和工具调用
  - 网络断开兜底：超时 30s 后切到普通 fetch 模式
  - Cloudflare Workers 原生支持 SSE，无障碍
- **状态**：每次对话独立（无 multi-turn），降低复杂度
- **失败回退**：Agent 解析失败 → 自动转走当前的 `parse-segments` 单轮模式

### 4.4 工期估算

| 任务 | 工期 |
|------|------|
| Agent 工具集设计 + 实现 | 3 天 |
| System Prompt 调优 | 2 天 |
| SSE 流式前端 UI | 2 天 |
| 多意图执行计划页 | 2 天 |
| 失败兜底 + 边界 case | 3 天 |
| 内测调优 | 3 天 |
| **合计** | **~2.5 周** |

## 五、明确不做的事情（MVP 阶段）

| 不做 | 原因 |
|------|------|
| 体态评估模块 | 拍照分析复杂度高，延后 |
| 多主题切换 | 一套主题做到极致即可 |
| C 端会员 App | 教练自用工具，不延伸 |
| 微信公众号对话 | 小程序 + H5 已足够 |
| 跨设备云同步 | localStorage 够用，云同步作为付费功能 |
| 排课冲突提醒（复杂版）| 简单提示即可，复杂逻辑延后 |

## 七、风险与缓解

| 风险 | 概率 | 缓解 |
|------|------|------|
| 周视图做不到"截图级" | 中 | 找设计参考 + 必要时请设计师出图 |
| 教练觉得 AI 不准 | 中 | 多段模式 + 审核步骤，错了能改 |
| Agent 模式过度复杂 | 中 | MVP 上线后再启动，不影响主路径 |
| ASR 10s+ 太慢 | 低 | 已可切 paraformer-v1 (5s)，给用户选择权 |
| Cloudflare 国内访问偶发慢 | 低 | 同源部署已规避，国内访问稳定 |
