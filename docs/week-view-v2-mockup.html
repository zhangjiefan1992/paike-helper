周视图 V2 — 自适应时间轴

核心改进：时间范围根据实际课程自适应（不再展示整天16小时空白），卡片获得足够高度显示内容。
下方展示同一周数据在两种主题下的效果。时间范围 09:00-20:30（由课程数据决定）。

soft-color 暖色主题
class-plan 冷色主题

设计说明

  • 自适应时间范围：只展示有课时段（最早课开始前30分 ~ 最晚课结束后30分），不浪费空间在空白时段
  • 一屏展示：无需滚动，所有课程在一屏内完整展示
  • 时长可辨：90分钟卡片明显高于60分钟，60分钟高于45分钟
  • 内容完整：每张卡片展示会员名 + 时间（空间不足时只显示名字）
  • 冲突并排：同时段重叠课程并排缩窄显示，互不遮挡
  • 左侧时间轴只标注整点，宽度仅28px，最大化课程展示区域
  • 三种密度设置控制默认展示范围（有课时自适应会覆盖）：
    • 宽松(relaxed): 09:00-18:00 — 适合只上白班的老师
    • 标准(standard): 08:00-21:00 — 多数场景
    • 紧凑(compact): 07:00-22:00 — 早晚都有课
