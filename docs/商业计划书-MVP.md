## 一、一句话说清

**一个微信小程序，帮自由教练在每节课后，用 3 秒发出一条专业的课程总结给学员。AI 自动写，教练只需点"发送"。**

---

## 二、谁在用？一个典型用户故事

> **小林，28 岁，自由普拉提教练。**
>
> 她不隶属任何场馆，自己接学员，在几个共享教室之间跑。每周 15-20 节课，学员 30 多人。
>
> 她现在的工作流：
> - 用微信备忘录排课 → 经常记错时间
> - 上课时给学员拍照 → 手机相册里几百张，分不清谁是谁
> - 下课发照片给学员 → 加一句"今天练了核心，记得拉伸" → 每节课重复
> - 学员问她"我最近进步了吗？" → 她凭印象回答，没有数据支撑
>
> **她每天花在"非教学"事务上的时间：约 40 分钟。**
>
> 她试过青橙、菲特云，太复杂了。"我就一个人，要什么财务报表？"
>
> 她想要的：一个极简工具，排好课、下课后自动生成总结发出去。**不要学，直接用。**

## 三、MVP 产品形态

### 3.1 三个核心功能

| 功能 | 描述 | 使用频率 |
|---|---|---|
| **排课** | 周视图拖拽排课，绑定学员和课程类型 | 每周 1 次 |
| **AI 课后总结** | 下课后 AI 自动生成一条专业课程总结，教练点"发送"即可 | **每节课后** |
| **学员档案** | 自动聚合学员所有课程记录和总结，形成时间轴 | 上课前看 |

### 3.2 核心体验：2 次点击完成课后总结

```
下课后打开小程序
  → 刚才上完的课程卡片上有红点 🔴
  → 点"发送总结"
  → AI 已经生成好了：
      "今天和小林完成了60分钟普拉提训练，
       重点练习核心控制和髋关节灵活性。
       相比上周，核心稳定性有明显提升，
       建议课后每天10分钟髋部拉伸。"
  → 点"发送"
  → 学员微信收到一条专业的课程复盘

教练操作：2 次点击。耗时：3 秒。
```

**AI 怎么知道的？**
- 这节课绑了哪个学员、什么课程类型、多长时间 → 课程数据
- 该学员之前的上课记录和教练备注 → 历史数据
- AI 根据这些自动生成个性化文案，不需要教练打字

### 3.3 产品哲学

| 设计原则 | 含义 |
|---|---|
| **零输入** | 能自动生成的绝不让人输入 |
| **3 秒完成** | 核心操作不超过 3 次点击 |
| **下课才用** | 不在课中打扰教练，下课后的 5 分钟窗口 |
| **学员能感知** | 产品好不好，学员收到什么比教练操作什么更重要 |

## 四、和现有产品的区别

| | 青橙/菲特云/SaaS | 排课助手 |
|---|---|---|
| 目标用户 | 场馆老板 | **自由教练本人** |
| 需要营业执照 | ✅ 必须 | **❌ 不需要** |
| 核心功能 | 会员管理 + 财务 + 营销 + 排课 | **排课 + AI 课后总结** |

| 商业模式 | ¥300-3000/年 订阅 | **¥68 买断 / ¥9.9 月卡** |

**排课助手不做"管理工具"，做"教学辅助工具"。**

## 五、商业模式

### 5.1 定价

| 版本 | 价格 | 内容 |
|---|---|---|
| 免费版 | ¥0 | 排课 + 会员管理 + **每周 3 次 AI 总结** |
| Pro 版 | **¥68 买断** | 无限 AI 总结 + 云同步 + 学员档案导出 |

**为什么是 ¥68？**
- 一杯咖啡 + 一顿饭的钱，冲动消费门槛
- 买断制：无续费焦虑，教练心理负担低
- 市场锚点：青橙 ¥19.9/月(≈¥240/年)，松果约课 ¥365/年
- 后续可做 ¥128 升级版（AI 学员成长报告、照片智能分类）

### 5.2 为什么免费版给 3 次 AI 总结？

免费教练用第一周 → 3 次用完 → 关掉小程序。

下一次上课 → 手机备忘录排课太麻烦 → 重新打开小程序 → 手动打字发总结，想起 AI 有多快 → 付 ¥68。

**关键：让教练先体验"3 秒发总结"的快感，再收回。**

### 5.3 盈利测算

| 用户量 | 转化率 | 收入 |
|---|---|---|
| 100 个免费用户 | 5% → 5 人付费 | ¥340 |
| 500 个免费用户 | 5% → 25 人付费 | ¥1,700 |
| 1,000 个免费用户 | 8% → 80 人付费 | ¥5,440 |
| 5,000 个免费用户 | 10% → 500 人付费 | ¥34,000 |

**基础成本：微信云开发 ¥19.9/月。** 一旦有 3 个付费用户就覆盖成本。

### 5.4 长期变现路径

```
当前（MVP）
  ¥68 买断：AI 总结 + 云同步

6 个月后（功能扩展）
  ¥128 升级：AI 学员成长报告 + 照片智能归档 + PDF 导出

12 个月后（网络效应）
  教练社区 → 教案模板市场 → 抽佣 30%
  教练与学员撮合 → 按线索收费
```

## 六、可行性分析

### 6.1 技术可行性：✅ 已验证

| 技术点 | 方案 | 状态 |
|---|---|---|
| 小程序框架 | 微信原生开发 | **已完成** — 排课、会员管理、数据导入导出已上线 |
| AI 文案生成 | 调用大模型 API（DeepSeek / 通义千问 / 腾讯混元） | **一行代码** — API 调用成本约 ¥0.002/次 |
| 云同步 | 微信云开发 CloudBase | **¥19.9/月** 基础套餐 |
| 微信支付 | `wx.requestPayment` | **一次调用** — 需先申请商户号（5-15 工作日） |

**AI 调用成本：**
- 每次总结消耗约 500-800 Token
- 按 DeepSeek API 价格：约 ¥0.001/次
- 一个教练每天 5 节课 → 一个月 ¥0.15
- 100 个付费用户 → 每月 AI 成本不到 ¥15

### 6.2 市场可行性：🔶 待验证

| 假设 | 验证方式 |
|---|---|
| "教练下课后会给学员发总结" | 问 10 个教练：你现在下课后做什么？ |
| "AI 写的总结和教练自己写的差不多" | 给教练看 AI 生成的示例，问问能不能用 |
| "¥68 愿意付" | 直接问：这个功能，你愿意付多少钱？ |
| "红点能驱动打开" | MVP 上线后看日活数据 |

### 6.3 竞争可行性：✅ 有空间

| 竞争者 | 和他们比 |
|---|---|
| **青橙/菲特云/SaaS** | 他们服务场馆老板，不服务自由教练。功能太重。 |
| **微信聊天** | 教练当前的"工具"。我们的差异化：自动生成文案、历史可查。 |
| **其他健身 AI App** | 100% 面向消费者（帮用户练），不是面向教练（帮教练教）。 |

**结论：自由教练的"课后总结"工具，市场上没人做。**
