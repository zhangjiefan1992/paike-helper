# 交互稿 · AI 备课助手

> **版本**：v0.1（草稿）
> **基准设备**：iPhone 12 / 13 (390×844pt)，小程序 + H5 通用
> **风格**：跟主产品一致的 editorial（serif 标题、hairline 分隔、暖纸背景）

---

```
│                                        │

│  [ 下次重点哪里 ] [ 评估近期进度 ]      │
│  [ 强度建议 ]   [ 注意事项检查 ]        │

│         ┌──────────────────┐           │

│         └──────────────────┘           │

```

**设计要点**：
- 顶部"AI 备课 · 王晓芳"明确身份，强化"基于这个会员"的价值
- 会员上下文显式列出（不藏，让教练知道 AI 看了什么）
- 输入框可空 + 快速选项，**两种入口都流畅**
- 底部 CTA "开始咨询" 用主色 ink，强调动作
- 没有"模式切换"——router agent 自动识别意图

**待访谈验证**：
- 4 个快速选项是不是教练真用的？还是要"心情" "动作选" "课程评估"？
- 上下文要不要可折叠？老用户可能嫌啰嗦

## C. 咨询进行中（流式）

提交后，输入区收起，显示 4 派 + 裁判：

```
┌─ AI 备课 · 王晓芳 ───────────────── × ┐
│                                        │
│  你问：下次重点哪里                     │  ← 用户消息回显
│  ─────────────                         │
│                                        │
│                                        │
│  ✦ 经典派 · 思考中...                   │
│  ─────────────────────────            │
│  从控制与流畅性出发，我观察到...         │  ← streaming
│  (打字机效果)                           │
│                                        │
│                                        │
│  ✦ 当代派 · 思考中...                   │
│  ─────────────────────────            │
│  基于生物力学评估，建议...               │  ← 并行 streaming
│                                        │
│                                        │
│  ✦ 康复派 · 思考中...                   │
│  ─────────────────────────            │
│  腰部曾有不适，应优先...                 │
│                                        │
│                                        │
│  ✦ 健身派 · 思考中...                   │
│  ─────────────────────────            │
│  适度提升强度，下身爆发...               │
│                                        │
└────────────────────────────────────────┘
```

**设计要点**：
- 4 派**并行 streaming**，4 个区块同时打字
- 状态显示 "思考中..."，完成时变 ✓
- 字段失败用"× 跳过"代替，不阻塞其他派
- 滚动跟随，最新一派在视口

## D. 咨询完成 · 综合建议

4 派完成后，下方追加裁判：

```
┌─ AI 备课 · 王晓芳 ───────────────── × ┐
│  (上面 4 派内容，可点折叠)              │
│  ✓ 经典派    ▸                         │
│  ✓ 当代派    ▸                         │
│  ✓ 康复派    ▸                         │
│  ✓ 健身派    ▸                         │
│                                        │
│  ═══════════════════════════           │
│  综合建议                               │  ← 这个最重要，serif
│  ═══════════════════════════           │
│                                        │
│  ◇ 共识                                │
│  优先核心稳定 + 髋部活动度，避后弯       │
│                                        │
│  ◇ 分歧                                │
│  · 强度：经典/康复偏温和；健身建议提强    │
│    → 由你判断（建议本周温和，下周提）   │
│                                        │
│  ◇ 推荐方案                             │
│  · 时长：60 分钟                        │
│  · 重点：核心稳定 / 髋部 / 呼吸控制      │
│  · 推荐动作家族：                        │
│    - 桥式系列                            │
│    - 仰卧腿环                            │
│    - 侧卧抬腿（避免脊柱旋转）            │
│  · 强度：中（避免大幅后弯 / 跳跃）        │
│                                        │
│  ◇ 注意                                │
│  ⚠ 课中观察腰部反馈，有不适立即降低     │
│  ⚠ 学员标签含"腰伤注意"，全程保持中立位 │
│                                        │
│  ─────────────────────────            │
│  ⓘ AI 生成，仅供参考；最终决定由教练做  │
│                                        │
│  ┌──────────────┐ ┌──────────────┐    │
│  │ 应用到下次课程 │ │  继续追问 →   │    │
│  └──────────────┘ └──────────────┘    │
│                                        │
│        [ 保存到客档 ]                  │
└────────────────────────────────────────┘
```

**设计要点**：
- 4 派完成后**默认折叠**为单行，点 ▸ 展开（信息层级清晰）
- 综合建议是**最大视觉重点**，serif 标题 ═══
- 共识 / 分歧 / 推荐方案 / 注意 是**结构化输出**，不是自由文本
- ⚠ 警告用 warm（terracotta 色）
- 免责声明 ⓘ 必带，灰色小字
- 三个动作按钮：
  - **应用到课程**（主动作 = ink 实心）
  - **继续追问**（次动作 = outline）
  - **保存到客档**（弱动作 = 文字链）

## 视觉语言摘要

| 元素 | 处理 |
|------|------|
| 标题 | Fraunces serif，大字号，-0.02em |
| 4 派标识 | ✦ + 流派名 + 状态 |
| 分隔 | hairline 1px，serif 双线 ═══ 强调段落 |
| CTA | ink 实心 / outline / 文字链 三层级 |
| 警告 | warm (#B5573D) terracotta |
| 数字 | 衬线 tabular-nums，跟其他衬线呼应 |
| 流式 | 打字机光标 / 4 派同时显示 |
| 折叠 | ▸ 单行预览，▾ 展开 |

## 待访谈验证的 UI 决策

1. **入口位置**：会员详情底部固定 CTA vs 顶部按钮 vs 周视图长按一并加？
2. **快速选项数量**：4 个 vs 8 个 vs 没有（让教练自己输入）？
3. **4 派输出默认**：展开 vs 折叠？
4. **裁判输出格式**：现有的 4 段（共识/分歧/方案/注意）OK？还是更简？
5. **多轮历史**：会员详情页要不要列？还是只在咨询界面显示？
6. **应用到课程**：哪些字段映射？focusAreas + notes 必映射，duration / intensity 怎么办？
7. **离线状态**：缓存最近一次咨询给教练课中查？
