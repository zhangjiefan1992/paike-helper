## P0 — 必须做（功能缺失，影响基本使用）

### 1. 设置页 — 预设配置可编辑
- [ ] 课程类型：增删自定义项
- [ ] 地点列表：增删自定义项
- [ ] 训练重点：增删自定义项
- [ ] 默认时长：可修改
- [ ] 工作时间段：可修改
> 当前 H5 设置页只有只读展示，无法编辑预设。小程序有完整的增删改。

### 2. 会员编辑 — 标签（tags）字段
- [ ] 会员表单增加 tags 字段（多标签输入）
- [ ] 会员列表显示标签
- [ ] 会员详情显示标签
> PRD 定义了 tags 字段（如"腰伤注意""新手""VIP"），当前 H5 会员表单缺失此字段。

### 3. 课程表单 — 地点选择增强
- [ ] 地点支持从预设列表选择（当前仅手动输入）
- [ ] 支持"+ 自定义"新增地点
> 小程序地点支持预设选择+手动输入，H5 目前只有手动输入框。

### 4. 课程卡片状态快捷操作
- [ ] 日视图：课程卡片支持快捷标记"已上""取消"
- [ ] 周视图：点击卡片跳转编辑
> 小程序支持左滑快捷操作，H5 可用按钮/下拉实现。
