## 一、产品概述

### 1.1 产品定位

「排课助手」是一款面向兼职私人教练和小型瑜伽/普拉提工作室的微信小程序。它是教练自用的课程管理工具，核心解决"排课信息散落在备忘录纯文本中，查看不直观、无法结构化跟踪"的痛点。

产品不依赖后端服务器，数据完全存储在用户手机本地，通过文件导出/导入实现备份与恢复。

### 1.2 目标用户

主要用户画像为 20-40 岁女性，包括自由职业瑜伽/普拉提教练、运动博主、小型场馆馆主。她们通常通过微信与会员沟通约课，在多个场地之间兼职授课，管理 10-50 个活跃会员，每周排课 10-30 节不等。

### 1.3 核心痛点

当前教练们普遍使用手机备忘录以纯文本方式记录排课信息，存在以下问题：

- **看排课不直观**：纯文本无法一眼看出一周哪天满了、哪天有空档。
- **协调困难**：和会员微信沟通后，需要来回翻备忘录确认哪些时段可用。
- **状态不明确**：哪些课已经上了，哪些被取消了，哪些还没确认，靠记忆或标记符号区分。
- **会员跟踪断裂**：同一个会员上了多少节课、练习节奏如何、历史备注是什么，没有时间轴可看。

### 1.4 产品目标（第一版）

第一版定位为教练个人自用工具，以"能用 → 好用"为原则，不追求社交和协作功能。架构层面预留主题系统扩展空间，为后续通过"视觉主题付费"探索商业化打基础。

## 二、技术方案

### 2.1 平台与框架

- **平台**：微信小程序（原生开发）
- **最低基础库版本**：建议 2.25.0+
- **不使用任何后端服务**，不使用微信云开发

### 2.2 数据存储

- **主存储**：`wx.setStorageSync` / `wx.setStorage`，数据以 JSON 格式组织。
- **存储上限**：微信小程序本地存储上限为 10MB，对于个人教练管理场景完全够用（纯文本数据约支撑数千条课程记录）。
- **照片处理**：课程关联的照片存储为本地临时路径或 base64 缩略图。由于存储空间限制，照片仅保留缩略图预览；原图建议用户自行保存到相册。
- **备份与恢复**：支持将全量数据导出为 JSON 文件（通过 `wx.shareFileMessage` 发送到微信聊天），以及从文件导入恢复数据。

### 2.3 主题系统预留

视觉层通过统一的主题变量（颜色、圆角、字体、插画资源路径）控制，第一版内置一套"动漫风"默认主题。架构上将主题配置抽离为独立模块，为后续支持多主题切换做好准备。

## 三、信息架构与数据模型

### 3.1 数据实体

#### 会员（Member）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 唯一标识，自动生成 |
| name | string | 是 | 会员昵称 |
| phone | string | 否 | 联系方式 |
| avatar | string | 否 | 头像（本地路径或默认头像） |
| tags | string[] | 否 | 标签，如"腰伤注意""新手""VIP" |
| notes | string | 否 | 备注信息 |
| createdAt | number | 是 | 创建时间戳 |

#### 课程记录（Session）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 唯一标识，自动生成 |
| memberId | string | 是（私教）| 关联会员 ID。团课可关联多个或为空 |
| memberIds | string[] | 否 | 团课参与会员列表 |
| date | string | 是 | 日期，格式 YYYY-MM-DD |
| startTime | string | 是 | 开始时间，格式 HH:mm |
| duration | number | 是 | 时长（分钟），默认 60 |
| courseType | string | 是 | 课程类型（瑜伽/普拉提/体能等，从预设列表选） |
| classMode | string | 是 | 授课模式："private"（私教）或 "group"（团课） |
| location | string | 否 | 上课地点（从预设列表选或手动输入） |
| status | string | 是 | 状态："scheduled"（已约）/ "completed"（已上）/ "cancelled"（取消）/ "noshow"（爽约） |
| notes | string | 否 | 课后备注 |
| focusAreas | string[] | 否 | 重点训练部位，如"核心""髋关节""肩颈" |
| photos | string[] | 否 | 课程照片（缩略图路径） |
| createdAt | number | 是 | 创建时间戳 |
| updatedAt | number | 是 | 最后更新时间戳 |

#### 预设配置（Config）

| 字段 | 类型 | 说明 |
|------|------|------|
| courseTypes | string[] | 预设课程类型列表，如 ["瑜伽", "普拉提", "体能训练"] |
| locations | string[] | 预设地点列表，如 ["XX瑜伽馆", "会员家中", "公园"] |
| focusAreaOptions | string[] | 预设训练重点列表，如 ["核心", "髋关节", "肩颈", "下肢"] |
| defaultDuration | number | 默认课程时长（分钟），默认 60 |
| theme | string | 当前主题标识，默认 "anime-warm" |
| workingHours | object | 可排课时间段，如 { start: "08:00", end: "21:00" } |

## 四、页面设计与功能描述

### 4.1 首页 — 周视图

这是用户打开小程序后的第一个页面，以"周"为维度展示排课全貌。

**核心体验**：一眼看清这周每天排了几节课，哪天满、哪天有空。

**功能要点**：

- 顶部显示当前周的日期范围（如"4月21日 - 4月27日"），左右箭头或滑动切换上/下周。
- 下方以 7 列布局展示周一到周日，每列内纵向排列当天的课程卡片。
- 每张课程卡片显示：时间、会员名、课程类型，用颜色区分课程状态（已约=主色调、已上=灰调/打勾、取消=删除线）。
- 空白时段以浅色块提示"可排课"。
- 点击任意一天的列头进入日视图。
- 点击某张课程卡片直接进入编辑。
- 右下角浮动按钮"+ 排课"快速新增。
- 顶部区域可选显示本周统计摘要：已排 X 节 / 已完成 X 节 / 取消 X 节。

### 4.2 日视图

点击周视图中的某一天后进入，以时间轴形式展示当天每小时的排课详情。

**核心体验**：看当天的完整日程，快速标记课程状态。

**功能要点**：

- 左侧为时间刻度（按可排课时间段显示，如 08:00-21:00），右侧对应时间块显示课程卡片。
- 课程卡片展示完整信息：时间、时长、会员名、课程类型、地点、状态。
- 向左滑动课程卡片露出快捷操作：标记"已上完"、标记"取消"。
- 点击课程卡片进入编辑页面。
- 点击空白时间段可快速新增课程（自动填入对应时间）。
- 支持左右滑动切换前/后一天。

### 4.3 课程录入 / 编辑

新增或编辑一节课程的表单页面。

**核心体验**：快速录入，常用值不需要手打。

**功能要点**：

- **日期与时间**：日期选择器 + 时间选择器，默认为从周视图/日视图带入的值。
- **时长**：滚轮选择或快捷按钮（45分钟 / 60分钟 / 90分钟）。
- **授课模式**：切换按钮选择"私教"或"团课"。私教模式选一个会员，团课模式可多选。
- **课程类型**：从预设列表选择，支持"+ 自定义"新增。
- **地点**：从预设列表选择，支持手动输入。
- **状态**：默认"已约"，可手动改为"已上""取消""爽约"。
- **课后备注**：多行文本输入。
- **训练重点**：标签多选（从预设列表），支持自定义新增。
- **照片**：最多添加 9 张照片，调用微信相册/拍照能力。
- 底部"保存"按钮。编辑模式额外显示"删除此课程"。

### 4.4 会员管理

#### 4.4.1 会员列表

展示所有会员，支持快速查找。

**功能要点**：

- 按最近上课时间倒序排列（最近活跃的排最前）。
- 搜索栏支持按昵称模糊搜索。
- 每行显示：头像、昵称、标签、最近一次上课日期、累计课程数。
- 点击进入会员详情。
- 右上角"+ 新增会员"。

#### 4.4.2 会员详情 / 时间轴

单个会员的完整画像与上课历史。

**核心体验**：回答"这个会员都上了什么课、练到哪了"这个问题。

**功能要点**：

- 顶部：会员基本信息（头像、昵称、联系方式、标签、备注），可编辑。
- 统计卡片：累计上课 X 节、本月 X 节、最近一次上课日期、最常上的课程类型。
- 下方为**上课时间轴**，按时间倒序排列该会员的所有课程记录。每条记录显示：日期、课程类型、地点、状态、训练重点、课后备注摘要。
- 点击某条记录可展开查看完整备注和照片。
- 时间轴支持按月份折叠/展开，避免记录过多时滚动过长。

### 4.5 设置

应用级配置与数据管理。

**功能要点**：

- **预设管理**：编辑课程类型列表、地点列表、训练重点列表、默认时长、可排课时间段。
- **数据导出**：一键将全量数据导出为 JSON 文件，通过微信"发送给朋友"或"保存到文件"完成备份。
- **数据导入**：选择之前导出的 JSON 文件，解析后覆盖或合并本地数据（提供选项）。
- **主题切换**：第一版仅内置默认主题，预留主题选择入口（灰显或隐藏），为后续扩展做准备。
- **关于**：版本号、反馈入口。

## 五、视觉设计方向

### 5.1 整体风格

第一版采用"动漫暖系"风格，面向 20-40 岁女性用户，强调亲和力与视觉愉悦感。视觉是本产品的核心竞争力之一，未来计划通过付费主题实现商业化。

### 5.2 设计关键词

柔和、温暖、圆润、动漫感、少女心但不幼稚、有呼吸感。

### 5.3 配色方向

主色调采用暖色系（如柔和的珊瑚粉、奶茶色、薰衣草紫），搭配大量白色和浅灰留白。状态颜色需要在暖色基底上清晰可辨：已约用主色、已完成用柔和绿、取消用浅灰。

### 5.4 字体与排版

使用系统默认字体，但通过字号层级、字重对比和充裕的行间距营造呼吸感。标题可考虑使用稍圆润的字体风格。

### 5.5 圆角与阴影

大圆角（12-16px），轻盈的投影（模拟纸片感），避免硬边和深色阴影。

### 5.6 插画与图标

图标采用线性 + 填充混合风格，线条略粗（2-3px）增加手绘感。关键页面（如空状态、首次使用引导）配动漫风格插画。预留插画资源路径在主题配置中，方便后续替换。

## 六、交互规范

### 6.1 导航结构

底部 Tab 栏包含三个入口：

| Tab | 图标 | 页面 |
|-----|------|------|
| 排课 | 日历图标 | 周视图（首页） |
| 会员 | 人物图标 | 会员列表 |
| 我的 | 设置图标 | 设置页 |

### 6.2 手势操作

- 周视图：左右滑动切换周
- 日视图：左右滑动切换天
- 课程卡片：左滑露出快捷操作（完成/取消）
- 列表页：下拉刷新（重新加载本地数据）

### 6.3 空状态设计

每个列表/视图在无数据时需要展示友好的空状态，包含动漫风格插画和引导文案。例如周视图空状态："这周还没有排课哦～点击下方 + 开始排课吧"。

### 6.4 操作反馈

所有写操作（保存、删除、状态变更）需提供即时反馈：轻量 Toast 提示 + 微振动（wx.vibrateShort）。删除操作需二次确认弹窗。

## 七、非功能性需求

### 7.1 性能

- 小程序启动到首页可交互 < 1.5 秒
- 本地数据读写延迟 < 100ms
- 页面切换动画流畅（60fps）

### 7.2 数据安全

- 所有数据存储在用户设备本地，不上传任何网络服务
- 导出文件为明文 JSON，用户可自行查看和编辑
- 无需登录，无需授权手机号或用户信息

### 7.3 兼容性

- 支持 iOS 和 Android 平台的微信客户端
- 最低支持微信版本：8.0+
- 适配主流屏幕尺寸（iPhone SE ~ iPhone 16 Pro Max / 常见 Android 机型）

## 八、第一版范围（MVP）与后续规划

### 8.1 第一版包含

- 周视图 + 日视图
- 课程录入/编辑/删除/状态变更
- 会员管理（增删改查）
- 会员上课时间轴
- 预设配置管理
- 数据导出/导入
- 一套动漫暖系默认主题

### 8.2 第一版不包含（明确排除）

- 会员端任何功能（不做会员自助预约、不做课表分享）
- 课时费 / 财务统计
- 微信消息提醒 / 通知推送
- 多教练协作
- 云端同步
- 多主题切换（仅预留架构入口）

### 8.3 后续可探索

- **主题商城**：付费解锁不同视觉主题（核心商业化方向）
- **课时包管理**：会员购买课时包、自动扣减、余额提醒
- **数据统计面板**：月度/季度课程数量、收入趋势、会员活跃度
- **会员端小程序**：让会员查看可约时段、自助预约
- **数据云同步**：引入微信云开发，实现多设备数据同步

## 九、开放问题

以下问题在第一版开发过程中可能需要进一步明确：

1. **照片存储策略**：小程序本地存储 10MB 限制下，照片的压缩策略和数量上限需要实测确认。
2. **团课会员关联**：团课模式下是否需要记录每位参加的会员，还是只记录团课本身的信息。
3. **数据导入合并逻辑**：导入时如果和本地数据有冲突（如同一个会员 ID），是覆盖还是合并，需要定义具体策略。
4. **课程冲突检测**：是否需要在录入时自动检测同一时段是否已有课程并提醒。
