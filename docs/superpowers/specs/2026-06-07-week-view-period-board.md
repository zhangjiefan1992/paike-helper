# 周视图友好展示：时段课表方案

> 日期：2026-06-07
> 方法：ralph-loop 风格用户故事 + 验收标准

## 目标

参考竞品课表页，将小程序周视图从连续小时网格改为四个时段分区的 7 天游览表，减少空白和文字截断，让兼职教练能快速扫出一周课程密度、每节课时间和会员。

## 用户故事

作为教练，我希望在首页一屏或短滚动内按「上午 / 中午 / 下午 / 晚上」查看一周课程，这样我可以快速知道每天哪个时段有课，而不是在大量空白小时网格里找小色块。

## 验收标准

- 周视图非空时显示左侧时段列和 7 天日期列。
- 课程默认按开始时间归入上午 `07:00-12:00`、中午 `12:00-14:00`、下午 `14:00-18:00`、晚上 `18:00-22:00`。
- 如果本周存在早于 `07:00` 的课程，上午起点动态向前扩展到最早课程开始所在整点，例如 `06:00-12:00`。
- 如果本周存在晚于 `22:00` 结束的课程，晚上终点动态向后扩展到最晚课程结束所在整点，例如 `18:00-23:00`。
- 每张课程卡始终显示开始时间和会员名。
- 标准/详尽密度下显示课程缩写，详尽密度下补充地点信息。
- 同一天同一时段多节课按开始时间纵向排列，行高自动增加，避免卡片互相覆盖。
- 同一天同一时段内的课程按开始时间做弱时间定位：例如上午行中 `07:00` 靠上，`10:00` 靠中后，`11:00` 更靠下。
- 如果同一格内课程时间过近导致重叠，则在该格内做最小间距避让，优先保证卡片可读。
- 周视图首页必须一屏展示完整 4 个时段和底部操作按钮，不依赖纵向滑动。
- 不同手机高度下，课表主体高度由窗口可用空间计算；课程多或屏幕矮时自动压缩卡片高度、间距和时段行高。
- 点击课程卡进入课程详情/编辑页，长按课程保留状态操作菜单。
- 点击空白时段进入新建课程，并预填日期和对应时段默认时间。
- 空周仍显示现有导入/新增空状态。

## 设计判断

连续时间轴适合桌面日历或单日视图，但 7 列移动端会把课程压成窄条。时段分区牺牲了分钟级定位，换来更高的信息可读性，更接近教练真实扫课表的心智：先看哪天、再看哪个时段、最后点进课程看细节。

最终采用混合方案：周视图不是完整系统日历，也不是纯分桶堆叠海报，而是「美观优先的语义课表」。四个时段保留海报式结构和大色块课程卡；时段内部保留时间位置感，让用户能通过空间大致判断早晚和空档。

首页周视图以一屏扫读为硬约束。纵向滚动会削弱小程序首页的确定感，也会让底部操作按钮和课表主体产生遮挡关系；因此周视图在必要时牺牲少量卡片高度，而不是让页面滚动。

## Frontend App Builder 视觉基准

概念稿：`docs/week-view-frontend-builder-concept.png`

设计系统修正：

- `课表`主题顶部使用深墨蓝；`静练`主题使用黑咖色、暖纸面和低饱和大地色，借鉴高端运动工作室气质但不使用品牌命名。
- 日期栏从深色反白改为浅色表头，降低压迫感。
- 左侧时段列改为浅色轨道 + 细强调线，避免“整堵深色墙”。
- 课表主体使用纸白底和极浅蓝灰分隔线。
- 课程卡使用高对比会员色块，时间和会员名强可读，课程/地点作为小字辅助。
- 底部操作区使用白色浮层、描边导入按钮和深蓝主按钮，贴近可截图分享的课表感。
